# Page Replacement Algorithm Simulator

## Project Description
The Page Replacement Algorithm Simulator is a Python-based application that demonstrates how different page replacement algorithms work in Operating Systems.

It simulates FIFO, LRU, and Optimal algorithms and displays page hits, page faults, and frame-by-frame execution.

## Technologies Used
- Python
- Streamlit
- Pandas
- Plotly

## Algorithms Implemented
1. FIFO (First In First Out)
2. LRU (Least Recently Used)
3. Optimal Page Replacement

## Features
- Enter a page reference string.
- Set the number of frames.
- Select a page replacement algorithm.
- View page hits and page faults.
- Compare the performance of algorithms using a chart.

## Installation

Install the required libraries:

```bash
pip install streamlit pandas plotly
```

## How to Run

Open the terminal in the project folder and execute:

```bash
python -m streamlit run app.py
```

Open the local URL displayed in the terminal to use the simulator.
